**VayuDrishti** is a mission-critical, high-frequency environmental telemetry command dashboard engineered for the **Jaipur Urban Core Sector (Sector 07)**. Designed with an Obsidian industrial/SCADA interface, it monitors localized micro-climate indices, PM2.5/PM10 particle dispersion, and sensor mesh health across key metropolitan hubs.

---

## ⚡ Core Operational Features

- **Subsystem Boot Sequence**: High-tech preloader simulating firmware check, memory allocation, and spatial sensor mesh synchronization.
- **Tactical Geospatial Radar**: Interactive, zero-watermark dark map monitoring real-time active nodes (*Sitapura Industrial Area*, *MI Road Commercial Corridor*, *Mansarovar Sector 7*) with an overlay 360° radar sweep.
- **Emergency Anomaly Simulation Mode**: Interactive crisis trigger injecting rapid PM2.5 inversion spikes, hardware fail-safes, real-time alert logs, and self-healing automated recovery.
- **Pure Web Audio UI**: Browser-native sound synthesis (Web Audio API) delivering real-time acoustic feedback for tactical commands and anomaly alarms without external media dependencies.
- **Predictive Trajectory Analytics**: Dynamic 48-hour atmospheric dispersion forecasting powered by Chart.js.
- **Adaptive Industrial SCADA Design**: Glassmorphism cards with dynamic cursor spotlight tracking and a native mobile-first bottom app bar for field operations.

## 🛠️ Technology Stack

- **Frontend Core**: Vanilla HTML5, Modern ECMAScript (ES6+)
- **Styling Engine**: Tailwind CSS (CDN), Custom Obsidian SCADA Design System
- **Geospatial Engine**: Leaflet.js with Tactical Inversion Cartography
- **Data Visualization**: Chart.js 4.x
- **Audio Synthesizer**: Native Web Audio API
- **Deployment & Hosting**: Netlify CI/CD with Git Version Control
